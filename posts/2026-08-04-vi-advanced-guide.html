i로 들어가고 Esc로 나온다.
여기까지가 “쓸 줄 안다”의 문턱이라면, 그 다음은 명령 모드를 조립하는 쪽이다.

오늘은 기본 편집을 넘긴 뒤에도 손이 자꾸 마우스로 가는 구간—모션, 오퍼레이터, 텍스트 오브젝트, 매크로, 레지스터—만 남긴다.
vim도 포함하되, vi 계열의 공통 문법을 기준으로 한다. GUI 플러그인 투어가 아니다.

전제: Normal이 홈이다

vi의 핵심은 입력 모드가 아니라 Normal이다.
여기서 키 한 번이 곧 명령이고, 명령은 동사 + 명사로 붙는다.

역할예감각
오퍼레이터(동사)d c y >무엇을 할지
모션(명사)w $ } f)어디까지
텍스트 오브젝트iw a" i(“단어/따옴표 안”처럼 덩어리

dw는 “delete + word”, c$는 “change to end of line”.
이 조합만 몸에 붙어도, 줄 단위로 지우고 다시 치는 시간이 줄어든다.

1) 모션을 키우면 오퍼레이터가 커진다

자주 쓰는 모션부터.

w / b / e     단어 앞·뒤·끝
0 / ^ / $     줄 맨앞 / 첫 글자 / 줄 끝
gg / G        파일 처음 / 끝
} / {         문단 단위
%             짝 괄호로 점프
fX / tX       이 줄에서 문자 X로 / 바로 앞까지
; / ,         직전 f/t 반복 / 반대

카운트를 앞에 붙일 수 있다. 3w, 2}, d5j.
“몇 칸”이 아니라 구조 단위로 움직이는 습관이 고급 사용의 시작이다.

검색 모션도 오퍼레이터와 붙는다.

/pattern<CR>   앞으로 검색
?pattern<CR>   뒤로 검색
n / N          다음 / 이전
* / #          커서 단어로 검색

d/foo<CR> — foo 직전까지 삭제.
마우스로 드래그하던 구간이, 한 줄의 명령이 된다.

2) 텍스트 오브젝트 — “안”과 “둘레”

모션이 선이라면, 텍스트 오브젝트는 덩어리다.
오퍼레이터 뒤에 i(inner) / a(around)를 붙인다.

diw   단어만 삭제 (공백 제외)
daw   단어+주변 공백 삭제
ci"   따옴표 안만 바꾸고 입력 모드
da"   따옴표까지 통째로 삭제
ci( / ci) / cib   괄호 안
dit / dat         태그 안 / 태그 포함 (vim)

코드를 고칠 때 제일 많이 쓰는 패턴이 여기 있다.
문자열·인자·블록을 눈으로 세지 않고 통째로 집는다.

시각 모드도 같은 문법이다.

v     문자 단위
V     줄 단위
Ctrl-v  블록(직사각형)

잡은 뒤 d/y/>를 누르면 된다.
다만 숙련될수록, 시각 모드보다 d/c + 오브젝트로 끝나는 경우가 많아진다.

3) 레지스터와 매크로 — 클립보드를 넘어서

기본 yank/delete는 "(unnamed) 레지스터로 간다.
여러 조각을 들고 다니려면 이름 있는 레지스터를 쓴다.

"ayy     a 레지스터에 줄 복사
"ap      a 레지스터 붙여넣기
"Ayy     a에 이어 붙이기 (대문자)
"+y      시스템 클립보드로 (vim, +clipboard)
"_dd     블랙홀 — 삭제만 하고 덮어쓰지 않음

실수로 dd 한 번 더 눌러 아까 복사한 내용을 날리는 경험, 다들 한 번쯤 있다.
"_d와 "0(최근 yank)을 알면 그 사고가 줄어든다.

매크로는 레지스터에 키 입력 시퀀스를 녹화하는 것이다.

qa          a에 녹화 시작
...편집...
q           녹화 종료
@a          재생
@@          직전 매크로 재실행
10@a        10번

반복 수정의 정석: 커서를 다음 타깃으로 옮기는 모션까지 매크로 안에 넣는다.
그러면 @a만 연타해도 파일이 한 줄씩 정리된다.

4) 치환·전역 — 파일을 한 번에 다루기

:s/old/new/         현재 줄, 첫 일치
:s/old/new/g        현재 줄, 전부
:%s/old/new/gc      파일 전체, 확인하며
:g/pattern/d        pattern 줄 삭제
:g/pattern/s/a/b/g  pattern 줄만 치환

c 플래그는 “일괄 치환이 무섭다”는 사람에게 안전장치다.
범위를 시각 모드로 잡은 뒤 :를 누르면 '<,'>가 자동으로 붙는다 — 선택 구간만 치환.

5) 창·버퍼 — 한 파일을 넘길 때

:e file     다른 파일 열기
:bnext/:bp  버퍼 이동
Ctrl-w s/v  가로/세로 분할
Ctrl-w w    창 순환
Ctrl-w q    창 닫기

탭(:tabnew)보다 버퍼 + 분할이 vi 감각에 가깝다.
파일을 닫지 않고 스택처럼 들고 다니면, 로그·코드·설정을 오가는 왕복이 짧아진다.

손에 남길 최소 세트

고급이라고 해서 키가 수백 개일 필요는 없다.
아래만 반복해도 “마우스 없이 고친다”에 가깝다.

  1. d/c/y + w/$/}/iw/i"/i(
  2. f / ; / %
  3. "_d / "ay / "ap
  4. qa … q / @a
  5. :%s//gc / :g//d

완벽한 vimrc보다, Normal에서 동사·명사를 조립하는 감각이 먼저다.
플러그인은 그 위에 얹으면 된다.

서버에 vi만 있는 날에도, 이 문법은 그대로 통한다.
그게 이 에디터가 아직도 살아 있는 이유이기도 하다.

참고: POSIX vi / Vim user manual 기준. 배포판·빌드에 따라 클립보드·태그 오브젝트 지원은 달라질 수 있다.
