# 애드센스 배치 가이드 — moyeo

Blogger + AdSense 기준. 수익과 가독성의 균형을 목표로 합니다.

## 원칙

1. **본문 먼저**: 글을 읽기 전에 광고가 화면을 덮지 않게
2. **자연스러운 끊김**: 문단·섹션 사이, 이미지 직후 등 “쉬어가는” 지점
3. **모바일 우선**: 첫 화면(above the fold)에 광고를 너무 많이 넣지 않기
4. **정책 준수**: 클릭 유도 문구(“광고 클릭”) 금지, 콘텐츠와 광고 혼동 금지

## 권장 위치 (Blogger)

| 위치 | 설명 | 우선순위 |
|------|------|----------|
| 본문 중간 | 대략 글의 40–60% 지점, 소제목 직후 | 높음 |
| 글 하단 | 본문 끝 ~ 관련 글/댓 위 | 높음 |
| 사이드바 | 데스크톱 전용, 스크롤에 고정되지 않게 | 중간 |
| 목록/홈 | 피드형이면 글 카드 사이 1곳 | 낮음 |

## 초안 작성 시

- 마크다운 초안에 `<!-- ADSENSE: mid -->`, `<!-- ADSENSE: end -->` 마커만 남긴다.
- Blogger에 붙여 넣은 뒤, 해당 위치에 AdSense 단위(또는 자동 광고)를 연결한다.
- 초안에 가짜 광고 HTML이나 “여기를 클릭” 문구를 넣지 않는다.
